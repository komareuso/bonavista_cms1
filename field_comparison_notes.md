# Field Comparison Notes

## Bonavista CMS landing page

The root page at `https://bonacms-5wz58zyw.manus.space/` currently presents a CMS-oriented landing page rather than a yacht detail page. The visible content includes a general fleet/CMS headline, high-level overview counters for published yachts, admin access, and media storage, plus CTA links such as fleet browsing and manager login. It does not expose detailed yacht-level fields such as dimensions, model year, beam, draft, toilets, engine, speed, rules, or pricing matrix.

## Barcelona Boat Rental page

The external yacht page exposes many yacht-level fields. These include yacht title, marina/location, boat type, rental type, capacity, length, minimum order duration, a multi-column seasonal pricing table, mandatory open bar pricing, inclusions, VAT note, swimmer/alcohol service note, waiter ratio and waiter pricing, coordination fee, internal ID, guests, crew/rental type, beam, draft, year, model, toilets, engine, cruising speed, equipment list, map/location block, terms and rules, reviews, similar boats, and booking request form fields.
